## Key Points & Lists

- [ ] Class 10 Marksheet (original + 5 photocopies, notarized)
- [ ] Class 10 Passing Certificate
- [ ] Class 12 Marksheet (original + 5 photocopies, notarized)
- [ ] Class 12 Passing Certificate
- [ ] School Leaving Certificate
- [ ] Transfer Certificate from school/college

- [ ] NEET Admit Card
- [ ] NEET Scorecard (original + 5 photocopies)

- [ ] Passport (original — must be valid for 5+ years from date of admission)
- [ ] Passport copy (first and last page) — minimum 15 photocopies
- [ ] 30–40 passport-size photographs (white/light background, as per university specs)
- [ ] Aadhar Card (copy)

- [ ] Birth Certificate (original + notarized copies)
- [ ] Medical Fitness Certificate (from a registered doctor, on letterhead, dated within 3 months)
- [ ] HIV Negative Certificate (mandatory for Russia, Kazakhstan, Philippines — recent test)
- [ ] Police Clearance Certificate / Character Certificate (required for Russia, Kazakhstan, Philippines)

- [ ] Bank Statement (showing adequate funds — typically 1 year of fees + living)
- [ ] Education Loan Sanction Letter (if applicable)
- [ ] Sponsorship Letter (if fees paid by parent/sponsor)

- [ ] Original Invitation Letter from Russian university
- [ ] Visa application form filled
- [ ] Embassy medical examination (done at Russian Embassy authorized centers)

- Get Class 10/12 documents notarized
- Apply for Police Clearance Certificate (takes 3–4 weeks)

- Apply for NMC Eligibility Certificate
- Get medical fitness done
- HIV test

- Visa application submission
- Passport submission to embassy
